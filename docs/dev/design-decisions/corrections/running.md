# Corrections: a running entry

How an entry that is still running is put right. Each decision follows the template in `../README.md`, and is cited by
its title.

## A running entry is edited at its start (2026-11-22)

**Built by:** Corrections.

**Decision:** a running entry heads both lists ("The main screen has a controls side and a dashboard") and opens in the
edit popup as any row does, but only its start and its profile can change. Its end is now: the now-line on the line,
with no handle and no time label of its own, and the result under the day shows its start alone. Its middle cannot be
dragged, so it never moves as a whole; it cannot be divided, and it has no "Ta bort": it is stopped first. Its start
docks onto an earlier entry of its profile as any handle does, and the joined entry runs on ("Two entries join by
docking"). Its break is set through its tag, as on any entry. A change needs a reason, as any edit; a reason alone may
be saved, as on any entry ("Every edit carries a reason"). Saved, it runs on from its new start, on its new profile,
marked edited if a time or its profile changed.

**Why:** a forgotten start is the commonest fix, and it is noticed while working; without this, the fix was to stop,
correct and start again, which split the entry in two and needed a join. A wrong profile, seen while it runs, is fixed
the same way. Keeping the end at now leaves nothing about a running entry that the clock has not yet settled.

**Rejected:** a running entry not editable at all, out of the lists until stopped: the commonest fix would take a stop,
a correction, a new start and a join. Its end editable too: it is now, and still moving.

**Cases:**

- Janitor work started at 08:25, really begun at 08:00: opened from its row, the start dragged to 08:00, "Glömde stämpla
  in", saved: it runs on from 08:00, marked edited.
- Started on "Utveckling" by mistake: opened, "Vaktmästare" picked, "Fel profil", saved: it runs on as janitor work from
  the same start.
- Running since 13:00, an entry of its profile 11:00–12:30 before it: its start docked onto 12:30 and let go: one entry
  from 11:00, still running, 12:30–13:00 green.
- Opened: no handle at its end, no "Ta bort", its middle not draggable.
