# Glossary

The project's terms. Use them as written, and add a term when it is coined. Reasons stay out (they are decisions), and
so does state. This index lists every term; read the part that holds the ones you are writing about. Other docs point at
a term by its name, never at a part.

**[A–E](a-e.md):** Added break, Afterglow, Balance, Base colour, Case, Ceiling, Ceiling wheel, Controls side, Dashboard,
Day total, Design token, Dimmed colour, Entry, Entry line, Errand, Expected hours.

**[F–Z](f-z.md):** Faded, Flex bar, Flex day, Full time, Gap, Handover, Hue (a profile's), Lit, Month, Neon, Opening
figures, Over colour, Pay category, Pay estimate, Peek, Pointer label, Pointer light, Profile, Prototype, Prune, Report,
Settings file, Sketch.
