# Glossary

The project's terms. Use them as written, and add a term when it is coined. Reasons stay out (they are decisions), and
so does state. This index lists every term; read the part that holds the ones you are writing about. Other docs point at
a term by its name, never at a part.

**[A–E](a-e.md):** Added break, Afterglow, Balance, Base colour, Case, Ceiling, Ceiling wheel, Controls side, Daily
copy, Dashboard, Day total, Design token, Dimmed colour, Entry, Entry line, Errand, Expected hours.

**[F–O](f-o.md):** Faded, Flex bar, Flex day, Focus outline, Full time, Gap, Handover, Hue (a profile's), Lit, Locked
panel, Month, Month line, Motion (Animerat, Stilla), Neon, Onboarding, Opening figures.

**[P–Z](p-z.md):** Padlock, Pay category, Pay estimate, Peek, Pointer light, Profile, Prototype, Prune, Reason (an
edit's), Recovery screen, Release, Report, Settings file, Sketch, Small deviations, Standing (a profile's), Tip, Today's
pie.
