# Glossary

The project's terms. Use them as written, and add a term when it is coined. Reasons stay out (they are decisions), and
so does state. This index lists every term; read the part that holds the ones you are writing about. Other docs point at
a term by its name, never at a part.

**[A–E](a-e.md):** Added break, Afterglow, Archived profile, Balance, Base colour, Case, Ceiling, Ceiling trend, Ceiling
wheel, Coming value, Controls side, Daily copy, Dashboard, Day total, Design token, Dimmed colour, Docking, Dropdown,
Entry, Entry line, Errand, Expected hours.

**[F–O](f-o.md):** Faded, Field, First day (the record's), Flex bar, Flex day, Focus outline, Full time, Gap, Handover,
Hue (a profile's), Lit, Locked panel, Month, Month line, Motion (Animerat, Stilla), Neon, Onboarding, Opening figures.

**[P–Z](p-z.md):** Padlock, Pay estimate, Pay kind, Peek, Pointer light, Profile, Prototype, Prune, Reason (an edit's),
Recovery screen, Release, Report, Scale (and step), Settings file, Shared look, Sketch, Small deviations, Spill (a
break's), Stacked, Standing (a profile's), Surface, Tip, Today's pie, Type set, Walk (an entry).
