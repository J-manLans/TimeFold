# Sketches

A quick try of one look before it is decided: a page each, opened in Firefox, with a toolbar of live controls. What a
sketch settles goes to its decision in `design-decisions/`, which holds every number; nothing here is a source for the
docs. A sketch is deleted once the code it previews is built, and `git log` keeps it.

- `type-sets.html`: the prototype's text sizes beside four sets (heading, body, label, caps heading) in rem, with a
  root knob, on the menu, the controls side, a popup and the dashboard.
